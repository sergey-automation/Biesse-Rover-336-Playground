# SIR88 RP2040 — стендовая прошивка, первая реализация

## Сборка Windows
Распаковать, например в `C:\Pico\sir88`. Использовать то же окно/окружение Pico SDK, в котором собирался blink. Переменная PICO_SDK_PATH должна указывать на SDK, с инициализированным TinyUSB. Компилятор ARM и Ninja должны быть доступны.

```cmd
cd /d C:\Pico\sir88
cmake -S . -B build -G Ninja -DPICO_BOARD=pico -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Результат `build\sir88.uf2`. BOOTSEL при подключении USB, скопировать UF2 на диск RPI-RP2. Не подключать исполнительные нагрузки станка. GPIO0 DI, GPIO1 DE, GPIO2 /RE, GPIO3 RO, общий GND, ST3485EBDR 3.3 V. LED GP25 горит во время пакета, погашен в ожидании. Текстовых логов USB нет.

## Python
```cmd
python -m pip install pyserial
python sir88.py --self-test
python sir88.py --list
python sir88.py --port COM7 --cmd 130 004 030 --expected 3 --xor 100
```
COM7 заменить фактическим портом. AUTO=0, RET=0 по умолчанию. Для первичной проверки только известная ранее Command чтения, без автоматических подтверждений. Результаты в sir88_results.json. Если нет ответа, проверять подключение/полярность A/B на обесточенном стенде. Скрипт не изменяет TX-слова.

## Границы проверки
Python self-test проверен. ARM-компиляция и стенд не проверены в среде создания: отсутствуют Pico SDK и ARM GCC. Это исходный проект, не проверенный UF2. Измерение задержки начала RS программное по флагу PIO; включает задержку наблюдения флага. Межсловный тайм-аут отсчитывается от наблюдения PUSH PIO около конца стопового бита; точность до такта не подтверждена. Переключение DE/RE программное, предварительная выдержка 80 тактов; требуется проверка. USB IRQ отключается на время отдельного обмена и разрешается между Command; USB обслуживается системно, прикладные команды только между пакетами. При фактическом зависании STOP не гарантирует остановку. Внутренние аварии прошивки и точность PIO требуют проверки на реальном контроллере. VID/PID тестовые, не для распространения серийного продукта. Flash во время работы не записывается.
